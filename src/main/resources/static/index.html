Developer note

Use Swagger UI to test the API. SAGA uses HttpOnly server-side sessions backed by Valkey/Redis and CSRF protection. Call GET /api/auth/csrf first; Swagger sends cookie XSRF-TOKEN as header X-XSRF-TOKEN. Successful login sets HttpOnly cookie SAGA_SESSION. There is no Bearer JWT for Auth V1. Google client secrets and environment credentials are never shown here.
